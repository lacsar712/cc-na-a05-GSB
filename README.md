# 航标灯光巡检台

登记航标实测光强和方位偏差，服务端当场给出合格或不合格。每条实测可签发回执，回执单独存档：签发当时冻结灯号、亮度、偏角、判词、附言、签发时刻和校验短串，下载时直接取存档原文，不现拼。改正实测亮度不影响已签发的回执，再签发一次才产生新的一张。页面由 Django 模板直接渲染，浏览器不另跑一套单页应用。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3190 |
| 应用 | http://localhost:8190 |
| PostgreSQL | localhost:54390 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| keeper | light123456 | 可登记、改正实测亮度、签发回执 |
| watch | watch123456 | 只读，可查看和下载回执存档 |

## 启动

```bash
cd projects/11-nav-aid-inspection
docker compose up --build
```

## 验收

1. 打开 http://localhost:3190 ，用 keeper 登录，列表里 LH-01 合格、LH-09 不合格。
2. 再登记一条光强低于要求的记录，结论为光强不足。
3. 换 watch 登录，没有登记入口；直接提交登记会拒绝。
4. 用 keeper 打开 LH-09 详情，进入回执册签发一张回执，下载的文本里有“光强不足”。
5. 把 LH-09 的实测亮度改高后，再打开刚才那张回执，正文仍是改之前的亮度；再签发一次才产生新的一张。
6. 换 watch 登录，能打开回执册并下载存档；提交签发或改正会被拒绝。
