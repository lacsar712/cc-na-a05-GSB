# 航标灯光巡检台

登记航标实测光强和方位偏差，服务端当场给出合格或不合格。页面由 Django 模板直接渲染，浏览器不另跑一套单页应用。

## 回执

每条实测可以签发一张回执。回执在签发时单独存档，冻结当时的灯号、亮度、偏角、判词和附言，并写下签发时刻与一段校验短串；下载时直接取存档正文，不现拼现下。

- 持灯账号（keeper）事后可以改正这条实测的亮度，结论随之重判；已经签发的那张正文保持签发时的原文，校验短串也不变。再签发一次才产生新的一张。
- 只读账号（watch）能进回执册、能下载存档，不能签发，也不能改正实测。
- 实测详情页提供签发、改正入口，并列出本条已签发的回执；全部存档进入回执册（/receipts/）。

## 验收

1. 打开 http://localhost:3190 ，用 keeper 登录，列表里 LH-01 合格、LH-09 不合格。
2. 再登记一条光强低于要求的记录，结论为光强不足。
3. 换 watch 登录，没有登记入口；直接提交登记会拒绝。
4. 用 keeper 打开偏暗种子 LH-09 的详情，点“签发回执”，下载回来的文本里要有“光强不足”。
5. 把该条亮度改高（如 1500），再打开刚才那张回执，正文仍是改之前的亮度与“光强不足”，校验短串不变；再签发一次才产生新的一张。
6. 换 watch 登录，能进回执册、能下载存档；没有签发和改正入口，直接提交也会拒绝。
